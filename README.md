# C++ Quiz Game

A simple console-based Quiz Game written in C++.

## Description

This program asks the user 5 multiple-choice questions and keeps track of the score. It provides immediate feedback for each answer and displays the final result at the end of the quiz.

## Features

* 5 multiple-choice questions
* Score tracking
* Input validation
* Supports uppercase and lowercase answers
* Instant feedback after each question
* Final performance evaluation

## Concepts Used

* Variables
* Constants
* User Input and Output (`cin`, `cout`)
* Conditional Statements (`if`, `else if`, `else`)
* Logical Operators (`&&`, `||`)
* Basic Program Structure

## How to Compile

Using g++:

```bash
g++ quiz-game.cpp -o quiz-game
```

## How to Run

Windows:

```bash
quiz-game.exe
```

Linux/macOS:

```bash
./quiz-game
```

## Example

```text
Welcome to quiz game!

Question no 1:
What is the capital of Pakistan?

A. Karachi
B. Lahore
C. Islamabad
D. Kohat

Answer: C

Good! correct answer
Score = 1 / 5
```
